# 赵坚九个人博客（高级动态版）

纯静态响应式个人主页，包含：
- 深色科技感 UI、渐变标题与玻璃拟态卡片
- Canvas 星点背景动画、缓慢漂浮光晕、滚动渐入效果
- 移动端导航
- 个人介绍、技术栈、项目经历、教育背景与荣誉
- 打印 / 保存 PDF、复制邮箱
- 技术栈补充：华为昇腾算子、Ascend C、CANN（按“了解”表述）

## 本地打开
解压后双击 `index.html`，用浏览器打开即可，无需安装依赖。

## 发布到 GitHub Pages
1. 在 GitHub 创建一个仓库，例如 `my-portfolio`。
2. 上传 `index.html` 到仓库根目录。
3. 进入 Settings → Pages。
4. 选择 Deploy from a branch，Branch 选 `main`，目录选 `/(root)`，保存。
5. 部署完成后，访问 GitHub Pages 显示的网址。

## 发布前提醒
网站公开后，页面中的手机号和邮箱会对访问者可见；请确认是否愿意公开。
